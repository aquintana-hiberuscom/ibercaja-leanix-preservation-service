# Contratos de integracion

Deben catalogarse individualmente:

1. Pathfinder o GraphQL.
2. Webhooks API.
3. Diagrams V2.
4. Navigation.
5. OAuth 2.0 client credentials.
6. Cosmos DB.
7. Azure Blob Storage.
8. Plataforma corporativa de logs.

Para cada contrato registrar: fuente, version/hash, operaciones evaluadas, operaciones permitidas, autenticacion, limites, errores, datos sensibles, test double, conectividad y estado de provision.

La existencia de un OpenAPI no demuestra autorizacion, provision ni conectividad.
